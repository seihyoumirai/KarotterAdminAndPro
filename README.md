# Karotter Admin and Pro

Karotterの管理者パネルと有料機能を解放する拡張機能です。

## 追加されるもの
- サーバー機能へのリンクをサイドバーと「もっと見る」項目へ追加
- 管理者パネルへのリンクをサイドバーと「もっと見る」項目へ追加
- 管理者パネルをクライアント側のみ解放
- 管理者パネルを全てのテーマに対応
- 有料機能「Karotter Pro」をクライアント側のみ解放
- クライアント側のみ最大固定カロート数を`2^32`に変更
- クライアント側のみユーザーに全てのバッジを付与
- クライアント側のみレベルを`2^32`に変更
- クライアント側のみ強制制限を解除

## 利用にあたって
1. 自作発言をしないこと
2. 二次配布をしないこと
3. 改造は許可
